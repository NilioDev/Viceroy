# Notes for Claude

See [CONTRIBUTING.md](CONTRIBUTING.md) for the clean-room rules and
[SECURITY.md](SECURITY.md) for the rules on reading outside files; they always
apply.

## Keep the README up to date

`README.md` is the project's front page for players. It must always match
the latest release and `main`. In every PR, if the change is something a
player notices (a feature, control, option, supported system, package, install
step, game-file handling), update `README.md` in the same PR. Build or
developer changes go in `CONTRIBUTING.md` or `docs/`.

- Don't put version numbers in the README.
- Never add screenshots or anything else made from the original game.
- Don't use the original game's title as our name, in the UI or in package
  names. The README may say in plain text which game Viceroy plays.
